# Preguntas sobre flujo de datos

## 1. Contexto general de la unidad

- ¿Cuál es la función principal de la unidad dentro de la institución?
  Almacenar recursos físicos (espacios) y bibliográficos para la universidad. 

- ¿Qué recursos académicos gestionan (salas, laboratorios, equipos, horarios, docentes, otros)?
  Libros, revistas, tesis, informes de práctica, juegos pedagógicos y no pedagógicos, computadores, salas de estudio, salas de silencio, bases de datos, libros digitales

- ¿Con quiénes interactúan (estudiantes, docentes, direcciones de carrera, otras unidades, proveedores)?
  Usuario estudiante, usuario académico y usuario comunidad en general o funcionarios, usuario acreditación, usuario jefe carrera?

- ¿Qué información reciben de cada uno y qué información les entregan?
  Cuando llega un usuario se recibe su RUT, y sus requerimientos.
  Cuando se pide por ej un libro, se entrega una ficha para cuando entregar el libro (informalmente). No existen credenciales que se entreguen.

## 2. Procesos principales

- ¿Cuáles son las tareas o procesos más importantes que realiza la unidad?
  Dar respuesta a procesos de acreditación, diagnóstico de recursos físicos y digitales, gestión para renovación de recursos físicos, cumplir con actualizar bibliografía, informes que carreras solicitan para proceso de acreditación (revisar bibliografía para carrera, estadísticas de uso de los libros y espacios físicos) 

- ¿Cuál es el proceso que más tiempo o trabajo les consume?
  Hacer estadísticas de uso, hacer constancias, revisar bibliografía (estadísticas), formateo y limpiar información que envia usuarios, hacer inventario (poco formal)

	Estadísticas en general se hacen de forma muy tediosa, ya que programa utilizado para esto no es especializado para estas labores, además de ser poco amigable con el usuario. 

- ¿Hay procesos que se repiten cada semestre o en fechas específicas?

	Cada año se actualiza base de datos de usuarios con datos de SAYD. Descarte de libros e inventario, controles de calidad, estadísticas de uso de recursos de cada departamento y en general.

## 5. Herramientas y problemas actuales

- ¿Qué sistemas o software usan hoy, y se comunican entre sí?
	Se utiliza el programa Horizont para la mayoría de procesos, para bibliografía, recursos, estadísticas de uso, inventarío, etc. También se usa word, drive, excel y gmail.

- ¿Qué tareas se hacen manualmente?
  Todo lo que no está implementado en software Horizont (proceso de acreditación, recolección de estadísticas específicas, visualizaciones, generación de constancias)

- ¿Dónde ocurren errores, retrasos o pérdidas de información con más frecuencia?
  Errores y retrasos ocurren en inventario al verificarse de forma no formal, y en general en todos los procesos en donde se tienen que hacer las cosas manualmente (ej, formatos inconsistentes, errores ortográficos, información faltante, etc).

- Si pudieran cambiar una sola cosa del proceso, ¿cuál sería?
  En general se valoriza mucho la autogestión del usuario y la automatización de los procesos.
