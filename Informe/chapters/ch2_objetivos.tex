\chapter{Objetivos}

Dado el diagrama en la figura 1, realizar las siguientes tareas:
\begin{enumerate}
    \item \textbf{Transformar el modelo entidad-relación en un esquema del modelo relacional}. En este esquema se deben utilizar las convenciones de nombres propuestas en el texto de estudio.
    
    Los dominios se deben definir de manera analítica considerando valores razonables o ejemplos buscados en la web.
    \item \textbf{Representar de forma gráfica el modelo relacional} —donde deben coincidir los tipos de datos definidos en el esquema utilizando la herramienta de diseño MySQL Workbench.
\end{enumerate}
